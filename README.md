# 🌐 Nexus 3D Digital Agency Landing Page

Nexus 3D, dijital ajanslar ve yaratıcı stüdyolar için tasarlanmış; modern, etkileşimli ve fütüristik bir web landing page projesidir. 3D animasyonlar, akıcı geçişler ve dinamik UI bileşenleri ile kullanıcı deneyimini üst seviyeye çıkarmayı hedefler.

---

## ✨ Öne Çıkan Özellikler

- 🧊 **3D & Etkileşimli Görseller:** WebGL / 3D animasyon entegrasyonu için optimize edilmiş modern arayüz yapısı.
- 📱 **Tam Duyarlı (Responsive) Tasarım:** Mobil, tablet ve masaüstü ekranlarda kusursuz görüntüleme.
- 🎨 **Modern UI/UX:** Dark mode estetiği, fütüristik tipografi ve özel renk paleti.
- ⚡ **Yüksek Performans:** Hafif ve modüler HTML5 / Tailwind CSS mimarisi.
- 🚀 **Smooth Animations:** Akıcı sayfa içi kaydırma ve mikro etkileşimler.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3, Tailwind CSS
- **Interactivity:** JavaScript (ES6+)
- **3D / UI Assets:** WebGL / CSS 3D Transforms
